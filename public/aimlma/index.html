या कार्यशाळेत तुम्ही काय शिकाल?

आधुनिक इंटेलिजंट सिस्टीम्सची सोप्या भाषेत सुरुवातीपासून माहिती:

१. AI, ML आणि Deep Learning चा परस्पर संबंध
AI च्या अंतर्गत Machine Learning आणि ML च्या अंतर्गत Deep Learning नक्की कसे बसते ते पहा.
२. Inputs आणि Targets ची संकल्पना
घराचे क्षेत्रफळ (Floor Area) हे Input आणि प्रत्यक्ष विक्री किंमत हे Target म्हणून समजून घ्या.
३. उदाहरणांच्या प्रशिक्षणातून अंदाजापर्यंत
सॅम्पल विक्रीवरून मॉडेल कसे शिकते आणि नवीन घरासाठी किमतीचा अंदाज कसा बांधते ते अनुभवा.
४. अंदाजाची अचूकता तपासणे
प्रशिक्षणादरम्यान बाजूला ठेवलेल्या घराच्या मूळ किमतीशी मॉडेलच्या अंदाजाची तुलना करा.
५. शिकण्याची सुरुवात कुठून करावी?
