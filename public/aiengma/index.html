१. AI Engineering म्हणजे काय?
सॉफ्टवेअर इंजिनिअरिंगच्या सहाय्याने AI मॉडेल्सना प्रत्यक्ष अ‍ॅप्लिकेशन्समध्ये कसे आणले जाते ते जाणून घ्या.
२. Prompts आणि API Requests
अ‍ॅप युझरच्या इनपुटचे रिक्वेस्टमध्ये कसे रूपांतर करतो आणि मॉडेलकडून उत्तर कसे मिळवतो ते फॉलो करा.
३. दोन प्रकारच्या Requests ची तुलना

४. लाईव्ह अ‍ॅप डेमो पहा

५. शिकण्याची सुरुवात कशी करावी?
प्रोग्रामिंग आणि API कॉल्सचा सराव करा, आणि एका स्पष्ट उद्दिष्टासह स्वतःचे पहिले AI फीचर तयार करा.
